Entrar como administrador

O portfólio é hospedado no GitHub Pages. Para publicar sem expor uma senha no site, use um token do GitHub com acesso somente a este repositório. A credencial é mantida apenas na memória desta aba e não é salva no navegador nem no repositório.

Criar token de acesso restrito ↗

No GitHub, escolha proprietário Galaduzbr → Only select repositories → Caique-Vilela → Repository permissions: Contents (Read and write). Token não é a senha da sua conta.

Nova certificação

Primeiro cole o link oficial. O sistema tenta identificar curso, emissor, data e ID; confira antes de publicar. Também aceita imagem do certificado para leitura automática do texto.
